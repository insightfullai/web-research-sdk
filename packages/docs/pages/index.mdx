# Insightfull Web Research SDK

Add event-triggered insightfull studies to your app in minutes.

[Get started](/docs/getting-started) [GitHub](https://github.com/insightfullai/web-research-sdk)

## How it works

- **Event tracking** — track clicks, pageviews, form submissions, and custom events
- **Trigger evaluation** — match events against your study triggers (event name or URL patterns)
- **Flexible display** — default overlay, custom modal, sidebar, or redirect — you control it

## Packages

| Package                               | Description                                              |
| ------------------------------------- | -------------------------------------------------------- |
| `@insightfull/web-research-sdk`       | Core SDK — track events, match triggers, display studies |
| `@insightfull/web-research-sdk-react` | React provider and hooks with SSR-safe initialization    |
