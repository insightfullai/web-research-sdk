## How it works

The SDK runs entirely on the **host side** of your application. It observes user sessions on real websites, captures behavioral signals, and manages a secure overlay bridge for interviews and guided tasks.

- **Behavioral capture** — clicks, input changes, form submissions, and SPA navigation with privacy-safe defaults (no raw text, no input values).
- **Overlay bridge** — connect a hosted overlay iframe through a versioned protocol with origin validation, capability negotiation, and graceful degradation.
- **Pluggable transport** — route captured events through your own backend via callbacks or `postMessage` with configurable batching.
- **React integration** — optional provider, hooks, and drop-in iframe component on top of the framework-agnostic core.
